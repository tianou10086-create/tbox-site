第一次使用 / Windows 10 · 11

先连模型，核验第一条答案。

不需要先买软件卡密。3 小时是软件运行试用，不包含免费云模型额度；使用自备模型时，第三方费用按服务商规则另计。

1. 连接模型2. 核验答案3. 处理错误设备自检

1. 填写你自己的模型连接

  1. 从下载页选择版本；日用默认稳定版 0.1.46，0.1.48 是独立测试版，不混用数据目录。
  2. 打开软件「设置」→「连接设置」→「回答模型」，将「回答来源」选为 personal。填写「自己的模型地址」「文字模型名称」「自己的模型密钥」，点「保存」。不要把本软件授权卡密当成模型密钥。已有密钥不会回显；仅同一地址下留空才保留，换地址时需填写新服务商密钥。
  3. 地址、模型名与密钥必须来自同一家服务。没有现成密钥时，先到你选择的服务商账户确认 API 权限及余额；本页不代办、不强制指定服务商，也不保证注册就送额度。
  4. 返回首页，展开「连接与诊断」，点「测试连接」。保留显示的状态和失败原因；测试本身可能产生服务商调用费用。「已填写」或 HTTP 200 不等于真实回答已验收。

上述入口名称已核对公开 0.1.46 源码；不同版本布局以实际界面为准。账号含模型套餐当前未开售，不是可跳过配置的免费入口。

2. 用一道无隐私题核验结果

先不录音、不上传简历。在练习的文字题入口输入：

80元商品先打七五折，再在折后价上加收10%。最终多少钱？请列出算式。

核验标准：66 元；80 × 0.75 × 1.10 = 66。逐项确认模型返回了文字、算式与结果可对照、没有把报错或截断当完成。保存本次结果或原始错误，再继续自己的材料。

这只是一次上手检查，不代表所有题都能答对。面试页中的财务数理题有已知拦截差异；若看到“不支持的数字/业绩”类提示，记录原题与入口，不把它当供应商余额问题，也不关闭保护规则。

图片识题还需单独填写服务商支持的视觉模型，并用无隐私图片验证；文字题通过不等于图片或语音也通过。

3. 按具体提示处理，不反复点生成

未配置 / 缺 API 地址、模型或密钥
回「设置」→「连接设置」补齐；别使用示例文字或别家服务的 Key。
401 / 密钥无效或无权限
核对服务地址与 Key 所属账户、模型权限。不要把密钥截图发到群里。
402 / 供应商余额不足
到该服务商核对余额。它不是 T-Box 软件试用时长或积分；确认后再测试连接，不重复发生成请求。
429 / 请求受限
保存提示和发生时间，稍后按服务商限制重试；连续点击不会增加额度。
连接超时 / 网络错误 / 原请求待核实
保留原问题和请求记录，先查网络及服务状态；有「恢复原请求」入口时沿原请求核实，不重复提交新单或新问题。
连接测试成功，但无答案 / 答错 / 文字截断
保留题目、模型名、原始提示与版本，到售后入口反馈。不要填写假的成功状态，不修改安装文件。

文字回答通过后，再检查音频与材料

  1. 使用软件音频设备自检，分别检查麦克风和系统回环；记录设备名称与逐项失败原因。
  2. 用固定短句核对本地转写文字，不把麦克风和系统声混为一条。是否安装了本地模型，以软件自检为准。
  3. 主动调用云端转写或视觉时，材料会发送给当前配置的服务商；录音留存位置、第三方保留规则与具名会议工具兼容性，尚无本页可核验的完整矩阵，不承诺零留存或全平台适配。
