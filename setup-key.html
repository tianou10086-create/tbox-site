首次使用指南

上场前不用碰运气。用自己电脑按下面顺序走一遍文字、声音、共享隐身与防拍快捷键，三分钟就能心中有底。

1. 登录与模型连接 2. 跑通文字、声音与看图 3. 防共享与防手机斜拍 4. 常见错误码排查 5. 本地资料与留存说明

1. 选择使用官方时长包或自备接口

先从 下载页安装客户端。走账户时长路线时，登录你在官网买过 体验包或小时包的账号即可直用，转写、回答和识图额度全包，不需要另购第三方 Key（已购旧时长积分包按原入口激活同步）。

如果要接自己的模型接口，打开「设置」→「连接设置」→「回答模型」，来源设为 personal，填入你自己的服务地址、模型名与密钥后保存。已有密钥不回显；换了服务地址务必同时更新对应密钥，切勿把软件授权码填进模型密钥框。

示例（使用川流 API 等 OpenAI 兼容服务时）：地址填 https://flurouter.net/v1 与已开通模型名；文字模型负责面试与对话，视觉模型负责笔试识图。软件本身仍按自备模式不扣平台时长，接口费按对应供应商结算。

2. 三分钟测稳这台电脑的设备状态

面试预演 先拖入一份 PDF 简历与目标 JD 完成「预分析」，返回主界面点一次「连接测试」，再放一段面试录像录音，看回环识别和提词出字速度是否流畅。
笔试演练 保持浏览器题干、选项完整展示在屏幕上，点「开始笔试」自动开启无焦点提词浮窗（首次冷启需几秒就绪），答完或退出时点「停止笔试」立即暂停计时。

不同声卡和会议软件在静音或独占模式下的表现各异；强烈建议用 ¥0.10 体验包在正式会议工具下实测一次。

3. 熟悉屏幕共享排除与防斜拍热键

  • 屏幕共享排除：主窗、提词浮窗及右键菜单默认标记系统级捕获排除（WDA_EXCLUDEFROMCAPTURE），常规微信/腾讯会议/飞书桌面共享与常规截图不可见；开启「增强置顶」或查看界面绿灯以复核状态。
  • 防手机偷拍护盾（v0.2.2+）：支持 cross 双向十字光栅、卷帘扫描条与非破坏 adaptive_dim 安全暗字。记住三个最常用的单手热键： Ctrl+Alt+S 轮换防拍档位、Ctrl+Alt+A 开关安全暗字、Ctrl+Shift+H 一键瞬间全隐身。
  • 手机同 Wi-Fi 秒隐身：手机扫描桌面端侧边生成的本机控制二维码，突发状况点一下直接隐藏电脑主窗口与浮窗。

4. 按原提示排查，不要连点重试

未配置地址 / 模型 / 密钥
回到连接设置补齐对应信息（若走账户包则切换回平台托管来源）。
401 / 无权限
核对账号登录状态、接口密钥或模型调用权限，切勿将密钥发到公开群截图。
402 / 余额不足
平台账户与第三方自备供应商账户彼此独立，对应到哪方充值去哪方补充。
429 / 频率受限
等待数秒后重试；连续狂点不会提高配额。
503 或原请求待确认
先查账户订单或报错记录并按原请求恢复，不重复提交付款。

5. 本地资料与数据留存目录

默认本地目录为 %LOCALAPPDATA%\TishiBox\suite（或启动命令指定的 --data-dir / 便携独立目录）。

  • 个人档案主文件 profile.dat 由当前 Windows 账户加密；结构化解析快照（如 profile/resume_parsed.json）与草稿/历史库（library.sqlite3、assessment.sqlite3）分开保存。
  • 软件内「移除材料」仅清理本次会话附件，不会连带删除磁盘原文件；导出与备份的文件请自行管理，不要通过手工篡改软件授权文件或内部校验树来尝试清理。
  • 本地转写音频只在内存内运行；使用云转写、云端回答或视觉识题时，相应数据会发往服务端处理。完整约定见 数据与隐私说明。
