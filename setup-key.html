首次使用指南（3 分钟上线清单）

建议在正式面试或笔试前至少半小时走完这几步：选好通道、导好简历、测通声卡和防拍快捷键，正式进场点「开始」直接稳住。

1. 登录或接自备模型 2. 导简历与实战自测 3. 防偷拍与扫码隐身 4. 常见提示怎么处理 5. 音频与笔试检查 6. 资料目录与清理

1. 登录账户开包，或填写个人 API 服务

如果你购买的是官网 V9 活跃云时长包（含 ¥0.10 体验包），从下载页装好软件后，直接用购买账号登录并核对余额即可，不用配置任何密钥（买过老版本积分包先在账户中心点首次激活再同步）。

如果你要用自己的模型服务，进入「设置 → 连接设置 → 回答模型」，把来源设为 personal，填同一家服务的 API 根地址、模型名与密钥（不要把 TBOX 账号密码/授权码填进密钥框）。

示例（使用川流 API 时）：回答来源选 personal，地址填 https://flurouter.net/v1 并填你在川流开通的模型名；文字模型管面试，视觉模型管笔试看图；川流用量由川流单独算钱。连接设置也支持单填本机 HTTP 代理端口，能直连保持留空。

保存后回首页展开「连接与诊断」点「测试连接」，提示成功后再顺道核对一次真实文字返回。

2. 拖入你的简历，并用实战题目走一遍

进场之前强烈建议先把你的 PDF 简历、目标岗位 JD 或面经文件夹拖进客户端进行预分析——这样现场出词才是你的真实项目数据与第一人称口吻，而且常见问法能实现毫秒直出。

面试热身题　打开 B 站或播放一段面试视频声，点击「开始面试」，观察右上角透明提词条是不是流畅切句出要点。
笔试热身题　打开浏览器保持静态题目画面完整露在屏幕里（注意避开同屏不断跳动的聊天窗口，减少屏幕稳态校验重算），点击「开始笔试」即可不切窗弹出浮窗与解析。

3. 启用防拍光栅护盾与手机一键藏窗（v0.2.2+）

  • 点客户端上的 「防拍 / 扫码隐身」 按钮可调出防拍光栅参数、4 档场景预设，以及局域网手机快速联动二维码。
  • 高频手势快捷键（不抢当前光标，单手随时切换）：Ctrl+Alt+P 开关光栅；Ctrl+Alt+S 一秒轮换「轻度护眼 → 均衡防拍 → 强效抗摄录 → 极隐暗光」；Ctrl+Alt+A 秒切低反差暗字；Ctrl+Shift+H 一键把主窗与浮窗统统藏起来。
  • 用微信扫描二维码（同一 Wi-Fi 下即可工作），手机点一下就能瞬间把桌面 TBOX 全隐身，或者遥控调整防拍光栅强弱。

4. 按原提示处理，不要连续瞎点或反复下单

未配置或缺少地址、模型、密钥
如果用的是官网时长包，确认已登录且账户包余额够；如果切到了 personal，补全服务地址、模型名和对应密钥。
401 / 权限错误 或 402 / 余额不足
属于你所填自备 API 服务商返回的认证或余额提示（请核对对应供应商后台余额），不要把密钥截图公开。
429 / 限流 或 503 / 请求超时
稍等数秒再发起，或者若弹出“原请求待核对”按界面恢复按钮续上原请求，连续猛点不会变快。
笔试画面“一直显示正在等待/识别中”
检查一下同一块屏幕里是不是开着实时滚动的视频框、聊天弹窗或动态网页广告——为防误识别，屏幕像素大面积不断变化会等待稳定帧，尽量只把静态考题留在视野里出题秒快。

5. 音频设备与系统录屏排除检查

  • 正式面之前务必点一次音频自检，核对默认播放设备（WASAPI Loopback）是不是你正在戴着的耳机或扬声器，如果混有多个虚拟声卡，直接在设置下拉里锁定目标输出设备 ID。
  • 想自己验证防共享效果：在客户端把浮窗显示出来后，随便拉一个系统截图工具或者腾讯会议自己跟自己测试共享桌面，确认共享画面里看不到提词字条与右键菜单。

6. 资料目录在哪 & 如何干干净净清理

确认数据根目录

默认保存在 %LOCALAPPDATA%\TishiBox\suite（如快捷方式指定了 --data-dir 则以对应目录为准；便携版也可使用独立数据文件夹）。

本地存放内容说明

  • 个人档案主文件 profile.dat 受当前 Windows 账户 DPAPI 加密保护；profile/resume_parsed.json 与解析副本是明文结构化文件；
  • 本地音频采集与本地 Whisper 转写走内存，但转写文本历史可留存在草稿/数据库（library.sqlite3、assessment.sqlite3）；使用云服务时会发给对应接口方并记录云会话用量。

清理前注意事项

请先把要留下的内容手动导出备份，再完全退出程序去处理对应数据目录。“移除附件/题面”仅撤销当次引用不删源文档；同样也切勿乱删目录中的授权状态文件以免引发异常。详情见数据与隐私条款。
