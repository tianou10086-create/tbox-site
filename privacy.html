数据与隐私 / 本页说明

本机处理主动使用云端网页与账户记录与清理

默认留在本机的材料

简历的导入与整理默认在本地。本地 SenseVoice 转写在本机处理录音；这与主动选择云端转写是两条不同流程。

检查实际选择的功能和服务，不要把“本地转写”理解成所有模型分析都会留在本机。

主动调用云端时，相关材料会发出

你使用云端模型、云端转写或视觉服务时，相关简历片段、录音或题面会按当前配置发送到所选服务商。保存规则与处理方式需查看对应服务商的说明。

不希望发送的身份证号、住址、电话等内容，请先删除或打码，再进行云端分析。不要公开完整 API Key、卡密、密码或验证码。

当前网页接收什么

网页账户尚未开放，不接收账户名或密码，也没有接入订单或支付关联；既有卡密仍在桌面软件中使用。

首页的方法练习笔记只在当前页面中编辑，不自动保存或发送。文档搜索由网页在浏览器内完成；为便于返回，会在本标签页的浏览记录条目中保留筛选，网页自身不上传搜索词。

反馈页只帮助整理文字，不会自动提交工单；你决定是否通过 QQ 售后群自行发送。访问公开网站、下载 GitHub 安装包或前往购买平台，仍会与相应网站建立连接；这不等同于上传你的练习笔记或本机材料。

记录、导出与卸载

卸载不保证自动清空所有记录。先导出需要保留的内容，再按实际软件说明处理本地数据；同时检查下载目录、桌面导出文件和回收站。

网页不能替你读取或删除本机的软件记录。需要协助时，先整理版本和错误提示，不要公开个人材料。
