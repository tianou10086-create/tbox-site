我的电脑能不能使用？

T-Box 当前面向 Windows 10 / 11 桌面电脑，不能直接在手机上运行。最低内存、独显及不同设备的表现尚未完成统一验证，先在自己的电脑上试用。

  1. 在 Windows 设置中确认系统版本。
  2. 确认有足够磁盘空间，准备一段自己的短句或不含隐私的练习题。
  3. 下载后分别检查音频和题面识别，不要仅凭安装成功判断全部功能正常。

下载之后，怎样核对安装包？

安装包校验只用于核对文件与官网公布的版本和 SHA256 是否一致，不会安装或运行软件。

完整指南包含定位文件、打开 PowerShell、可直接复制的比对命令，以及一致、不一致和找不到文件时的下一步。

免费试用的 3 小时怎么计算？

免费试用累计 3 小时，只在软件实际运行时计时。关闭软件后不继续计时，再次打开从剩余时长继续。

先完成设备与模型配置核对，再用自己的题目测试。网页无法读取本机试用剩余时间，请以桌面软件实际显示为准。
