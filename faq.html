我能不能用

我电脑能用吗？

目前面向 Windows 10/11。不同模型的内存与显卡需求不同，请先用免费试用完成设备自检和一段短音频测试，再决定是否购买。

首次使用请允许麦克风、系统声音和屏幕采集权限；先用试用版检查自己的声卡和显示器。

我专业不对口能用吗？

能。它是通用求职辅助，不限专业，也不限定行业。

我英语不好能用吗？

能。不会英语不影响使用；中文题面和中文表达可直接使用。

英文题面或英文面试请先用试用版测试识别和提示效果，再决定是否购买。

手机上能用吗？

不能直接用。TBOX 是 Windows 桌面软件，手机端暂不运行。

它到底干什么

它会替我答题吗？

不会。它只给结构化提示，最终说什么由你决定。

面试时它能听见对方说话吗？

能听见已授权采集的麦克风或系统声音，并尝试转成文字。

没有采集权限、声音太小、噪声太大或多人同时说话时，转写会漏字或延迟；它不会凭空听见未采集的声音。

它是实时弹出答案，还是我自己查？

它会在你触发后显示提示，你根据提示组织回答，不用手动翻资料。

提示来自当前转写、题面或你提供的材料；网络、权限和模型状态会影响出现速度。

它能帮我改简历吗？

能做结构和表述建议，不能替你保证经历真实或承诺录用。

你可以让它检查岗位匹配、项目描述和错别字；姓名、日期、数字等事实请自己核对。

我的数据安全吗

我的简历会被上传吗？

使用云端回答、视觉分析或模型辅助导入时，提交的文字、上下文或图片可能离开本机。不要把“导入”理解成绝不联网，也不要假定软件会自动删掉敏感字段。

已核对的 0.1.46 / 0.1.48 源码中，个人档案主文件 profile.dat 使用当前 Windows 账户加密；简历导入另存的 resume_parsed.json 及上一版 resume_parsed.prev.json 是明文结构化快照，不是原始全文。配置可用模型后，辅助解析可发送提取文字。请先去除不想发送的身份证号、住址等，再导入或分析。

本地路径及版本区别见资料留存与清理说明。

我的录音会被保存吗？

已检查的采集与转写代码使用内存音频，未在该处理路径写出录音文件；这不等于产品、系统和服务商都“零留存”。转写文字可能进入本地加密草稿或历史。

本地转写路径不需向云转写服务发送音频；云转写则会上传音频。平台云转写实现还会在服务器内存暂存字幕，并保留会话和用量记录：停止后并非立即清空，也不能承诺五分钟自动删除。服务商的保留、训练用途及删除期限尚未核实，不能承诺零留存。

平台含模型与云转写功能是否可用，仍取决于实际开放状态；这里说明数据边界，不代表已开放。

你们能看到我的面试内容吗？

取决于实际使用路径。个人模型连接将请求发给你配置的服务；平台模型路径会接收并转发材料，不能承诺平台“看不到”。

已核对的平台实现中，新含模型接口不在业务数据库保存问题和回答正文，但保留请求状态、用量及对账记录；旧积分接口会加密缓存回答以便恢复。若启用精确计数，计数服务也会接收消息内容。接口尚未开放不等于已经对用户提供服务。

这些结论不覆盖代理日志、系统备份或第三方留存；加密、缓存指令和“不记日志”标志，都不是全链路不保存的保证。

卸载后数据会删干净吗？

不能保证。移除资料只移除本次附件引用，原文件和资料库不随之删除；卸载或清理本地文件也不会删除平台及服务商记录。

先导出要保留的内容，再按版本与实际数据目录逐项处理。尚无已验证的一键清除全部资料、缓存、历史和云端记录的功能。不要为清理资料删除授权、设备密钥或安装目录。
