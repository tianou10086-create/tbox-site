购买后需要注册吗？

离线产品卡兑换不要求注册账号。网站已配置 16688 商家购买入口；能否下单、支付与交付请核对商家页面和实际订单。不同卡格式的入口见激活教程。

为什么要安装根证书？

测试版用本地根证书签名，让 Windows 能校验安装器与产品内部组件。安装器会在安装时把这张根证书加入本机信任库；卸载时它会弹窗问「是否同时删除根证书」，选「是」。选「否」的话这张自建根会一直留在你的信任库里——它不在微软公信根名单内，留着没用。也正因为是自建根，安装之前系统并不认这个签名，这就是下面那条提示的由来。

卸载后那张根证书还在吗？

取决于你在卸载确认框里点的哪个按钮。选「是」——已经删掉；选「否」——还在。想手动确认或清理：certutil -store Root "T-Box Local Root CA" 能查到就是还在，用以管理员身份运行 certutil -delstore Root "T-Box Local Root CA" 即可删除。

Windows 提示「已保护你的电脑 / 未知发布者」，要不要继续？

先暂停核对来源与文件哈希。确认可信之后，再自行决定是否点更多信息 → 仍要运行。原因是那张本地根证书在安装之前还没进系统信任库，不是文件坏了。判断文件有没有被调包别看这个提示，看 SHA256：下载页给了期望值和 Get-FileHash 命令，只能证明它与该期望值一致；期望值本身也必须来自你信任的发布渠道。自签证书谁都能造一张同名的，哈希对不上就别运行。

浮窗会出现在屏幕共享里吗？

提示盒使用内容保护标志降低录屏暴露；不同会议软件和独占全屏的表现以现场环境为准。

答案为空怎么办？

先核对网络与模型配置，查看软件右下角状态栏；可以尝试“一键恢复”。没有余额页。不要修改安装目录文件，若仍失败请保留日志与原始错误。

如何校验安装包？

在 PowerShell 运行下载页给出的 Get-FileHash 命令，对比页面 SHA256。

去下载试用版
现在买了卡密能激活吗？

当前产品 TB-YYYYMMDD-PLAN-SEQ4-CHK4#签名 卡采用 Ed25519，由产品卡密兑换入口在本机验签。旧启动器 TB1. 卡采用 RSA-SHA256，两套格式不可混用。网页校验通过不等于订单已交付或软件已激活，具体步骤见激活教程。

那现在怎么试用？

未激活免费试用为累计实际使用 3 小时，不是下载后 7 天；仅产品运行时计时，关闭后暂停。用尽后暂停该试用入口，授权是否生效以软件内状态为准。下载构建与当前源码的同步情况须按实际版本核对。

授权离线，是不是所有功能都不联网？

不是。卡密验签是本地操作；云端转写会发送音频，云端回答或视觉分析会发送相关文字、图片和上下文。模型下载、更新与商家支付也有各自网络请求。详见下方数据与隐私说明。

离线授权能远程吊销、换机或续期吗？

本机验签不能实时查询全局吊销或兑换状态；旧 TB1. 绑机规则与当前产品卡不同。换机、续期或退款后的授权处置须按订单人工核对；本站不承诺已实现远程吊销或全局防重复兑换。

免费累计 3 小时和付费体验卡 7 天有什么区别？

免费试用按实际运行累计 3 小时；体验卡是付费的标称 7 天档位，价格不变。当前产品卡源码从兑换时计算标称期限，另有 1 天宽限，不与免费试用自动顺延；旧 TB1. 卡依载荷中的绝对到期时间。网页不推算最终到期时间，请核对软件兑换结果。

能导入录音或视频文件转写吗？

不能，而且这是刻意的设计取舍。本产品只处理实时采集的麦克风与系统声音（soundcard 采集 → 声学模型），不支持导入 .mp3 / .mp4 / .wav 这类已有音视频文件。这样做换来三个好处：安装包更小、启动更快、并且不随包分发任何 GPL 音视频编解码器（如 x264 / x265 / SvtAv1Enc）。如果你需要转写已有录音，请先用其他工具转成文字再粘进来。

数据与隐私：先分清本机与云端

在 Windows 上，设置（可能含模型 API key）、草稿与面试历史使用当前用户 DPAPI 保护；答题 JSONL、诊断 trace、题库与资料库 SQLite、启动错误记录可能是明文。常用数据目录为 %LOCALAPPDATA%\TBoxData，未指定目录的源码默认 %LOCALAPPDATA%\TishiBox\suite。获得该账户或文件访问权限的程序可能读取这些数据；DPAPI 不是对同账户程序的隔离。

本地 Whisper 转写本身在本机运行；选择云端转写会将采集音频发送给配置的转写服务。云端回答与视觉分析会发送相关题面、转写、文档上下文及图片，API key 用于所配服务的鉴权。第三方接收方、所在地、保存和训练规则应在启用前逐项核对，不能把“离线验签”理解成“所有数据不上网”。不要提交无权处理的他人录音、简历或考试材料。

部分日志有体积上限，面试历史最多保留最近 100 条；没有证据表明其余数据会按天自动删除。可先在软件可用的导出功能备份所需记录，再关闭软件，通过订单售后渠道请求数据查阅、删除或问题处理；删除入口、保存期限及第三方清理流程仍待完善。本站当前不是一份已完成的全产品隐私政策，运营主体名称及独立隐私联系渠道尚待补齐。
