我能不能用

我电脑能用吗？

目前面向 Windows 10/11；最低内存与独显要求尚未完成统一验证。请先下载试用，在自己的设备上确认转写和读屏表现。

展开

首次使用请允许麦克风、系统声音和屏幕采集权限；先用试用版检查自己的声卡和显示器。

我专业不对口能用吗？

能。它是通用求职辅助，不限专业，也不限定行业。

我英语不好能用吗？

能。不会英语不影响使用；中文题面和中文表达可直接使用。

展开

英文题面或英文面试请先用试用版测试识别和提示效果，再决定是否购买。

手机上能用吗？

不能直接用。T-Box 是 Windows 桌面软件，手机端暂不运行。

它到底干什么

它会替我答题吗？

不会。它只给结构化提示，最终说什么由你决定。

面试时它能听见对方说话吗？

能听见已授权采集的麦克风或系统声音，并尝试转成文字。

展开

没有采集权限、声音太小、噪声太大或多人同时说话时，转写会漏字或延迟；它不会凭空听见未采集的声音。

它是实时弹出答案，还是我自己查？

它会在你触发后显示提示，你根据提示组织回答，不用手动翻资料。

展开

提示来自当前转写、题面或你提供的材料；网络、权限和模型状态会影响出现速度。

它能帮我改简历吗？

能做结构和表述建议，不能替你保证经历真实或承诺录用。

展开

你可以让它检查岗位匹配、项目描述和错别字；姓名、日期、数字等事实请自己核对。

我的数据安全吗

我的简历会被上传吗？

不一定。导入和整理默认在本地；你主动使用云端模型时，相关片段才会发出。

展开

不想发送的身份证号、住址、电话等内容，请先删除或打码，再进行云端分析。

我的录音会被保存吗？

本地转写可不上传音频；云端转写会发送音频，保存规则按服务商说明执行。

展开

你可以优先选择本地 SenseVoice 转写，并在使用后删除本地记录。

你们能看到我的面试内容吗？

我们不会主动查看；你选择云端处理时，对应内容会经过所选服务商。

卸载后数据会删干净吗？

不会保证自动清空。卸载前先导出需要的记录，再按文档删除本地数据目录。

展开

如果电脑由多人使用，请同时检查下载目录、桌面导出文件和回收站。

出问题找谁

装不上怎么办？

先重启电脑，再用管理员权限安装，并确认 Windows 10/11 和磁盘空间正常。

展开
  1. 不要关闭安全软件；先核对文件来源和 SHA256，保留拦截名称与错误提示。
  2. 仍失败时记录错误截图、Windows 版本和安装包版本。
  3. 通过 QQ售后群 1127804697 发来信息。
卡密输了不生效怎么办？

先核对字母数字，再确认电脑联网、时间正确且未超过有效期。

展开
  1. 从原始订单复制卡密，避免空格和全角字符。
  2. 重启软件后再激活一次。
  3. 保留订单号、错误提示和版本号，联系 QQ售后群 1127804697。
