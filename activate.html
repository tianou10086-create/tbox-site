激活与授权

按订单提示确认到账、激活权益，再到桌面端核对。授权码与个人模型 API 密钥切勿混填。

  1. 下载并登录、确认设备

    从官网下载当前版本。先用文字题检查连接，再核对声卡与视觉。使用指南

  2. 登录并查看已有订单

    在账户中心核对原订单、金额与交付状态。新时长包可在官网价格页直接购买。
    登录账户购买或查看订单 · 查看订单指引

  3. 确认到账与交付

    以服务端确认状态为准。若返回页中断先查原订单，未确认前勿重复扫码支付。

  4. 在桌面端核对权益

    新时长包到账后在账户中心点击「激活并加入时长池」，再以同一账号登录桌面端同步余额。多个新包自动合并累加。

遇到“原请求已保留”

继续用相同账号与原单恢复即可，不要另建新账号或反复提交支付。
