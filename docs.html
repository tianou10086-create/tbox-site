开始使用#

我的电脑能不能使用？

T-Box 当前面向 Windows 10 / 11 桌面电脑，不能直接在手机上运行。最低内存、独显及不同设备的表现尚未完成统一验证，先在自己的电脑上试用。

  1. 在 Windows 设置中确认系统版本。
  2. 确认有足够磁盘空间，准备一段自己的短句或不含隐私的练习题。
  3. 下载后分别检查音频和题面识别，不要仅凭安装成功判断全部功能正常。

下载之后，怎样核对安装包？

先核对版本与文件名，再用 PowerShell 读取文件的 SHA256，与下载页公布的值逐位比较。命令只读取文件，不会运行安装包。

Get-FileHash -LiteralPath '安装包的完整路径' -Algorithm SHA256

相同：文件与公布值一致，但不是病毒检测或安全认证。不相同：先不要运行，重新从版本页下载后再检查。路径报错时，重新确认实际文件路径。

免费试用的 3 小时怎么计算？

免费试用累计 3 小时，只在软件实际运行时计时。关闭软件后不继续计时，再次打开从剩余时长继续。

先完成设备与模型配置核对，再用自己的题目测试。网页无法读取本机试用剩余时间，请以桌面软件实际显示为准。

音频与识题#

麦克风没有输入，先看什么？

先区分麦克风输入和系统声音回环。录不到自己的声音时，先看软件选择的设备名称和 Windows 麦克风权限，不要先改模型配置。

  1. 用自己的短句检查麦克风输入。
  2. 核对当前选择的输入设备、权限及设备是否被占用。
  3. 记录实际设备名称、失败提示和复现步骤，再准备反馈。

音频与识题#

听得到自己，听不到电脑声音？

麦克风与系统回环是两条输入通道。播放一段本机声音，检查回环通道是否有输入；不要把“麦克风有电平”当作回环也正常。

核对音频权限、输出设备与设备占用，分别记录两条通道的结果。转写会受音量、噪声、多人同时说话等因素影响。

音频与识题#

读屏识题漏字或理解不对怎么办？

先用不含隐私的题面测试，确认采集范围包含题干、条件和选项。先核对识别内容，再判断参考思路。

  1. 检查屏幕采集权限和实际选取范围。
  2. 检查题干、数字、英文与选项是否完整。
  3. 识别正确但参考不合理时，记录所选模型和原始提示，保留自己的判断。

识别与模型理解都可能出错；不能把出现文字当作结果正确。

配置与数据#

卡密激活成功，为什么模型还不能用？

产品授权与模型连接是两条链。卡密决定 T-Box 使用权限；模型 Key、网络、配额和视觉能力取决于你选择的服务商。

核对所选服务的配置、网络及额度，保留原始错误提示。T-Box 卡密不包含第三方模型调用额度。

不要把完整 API Key 粘贴到公开群聊或反馈模板中。

配置与数据#

哪些数据留在本地，哪些会发到云端？

本地 SenseVoice 转写在本机处理录音。主动调用云端模型、云端转写或视觉服务时，相关材料会按当前配置发送到所选服务商。

导入和整理默认在本地；调用云端分析前，先删除或打码不需要的身份证号、住址、电话等内容。不同服务的保存规则需要查看相应提供方说明。

卡密输入后没有激活成功怎么办？

  1. 从原始订单复制卡密，避免额外空格和全角字符。
  2. 核对软件版本、电脑时间、订单期限及实际错误提示。
  3. 不要混用旧协议卡与新产品卡，也不要手工修改安装目录。
  4. 保留订单信息、错误文本和发生时间，通过现有售后渠道核对；不要公开完整卡密。

到期、续期和退款怎样处理？

一次性卡密不自动续费，到期不会自动扣款。需要继续使用时购买新卡，按桌面端流程完成激活。
