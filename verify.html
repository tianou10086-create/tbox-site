安装包校验指南

这是安装前的文件检查，不会安装、启动或修复 T-Box。

当前对应版本

0.1.37 / Windows 安装包
1. 找到文件2. 打开 PowerShell3. 复制并比对4. 看结果
返回下载页 →

1. 找到实际下载的安装包

在浏览器下载列表选择“在文件夹中显示”，确认实际文件名为 TBox-Setup-0.1.37.exe。本指南对应版本 0.1.37、大小 108,771,736 bytes。

如果实际版本不同，先到对应原始发布页取得该版本的校验值。文件名有“(1)”等后缀时，也应复制这个实际文件的完整路径；不要猜个人下载目录。

2. 打开 PowerShell，准备粘贴实际路径

在文件资源管理器中选中安装包，按住 Shift 右键，选择“复制为路径”（部分版本称“复制文件地址”）。然后在开始菜单搜索并打开 PowerShell。普通窗口即可，不需要更改执行策略。

粘贴下方完整命令后，窗口会显示 Paste the full installer path。在这个提示后粘贴刚复制的完整路径并按 Enter；路径只在你自己的 PowerShell 中输入，不交给网页。命令不依赖当前文件夹。

3. 复制完整比对命令

预期 SHA256（仅用于 0.1.37 安装包）：

E97A6863403CFF0579AA5830A7DA683484F127B2E5D52DE841933DF6361430ED

这段命令使用 Get-FileHash；该命令不可用时使用系统 .NET SHA256 读取同一个文件。两条路径都只检查文件是否存在并读取 SHA256；不下载脚本、不更改执行策略、不关闭安全软件，也不运行安装包。无 JavaScript 时可手动选中上方命令复制。

4. 根据实际输出继续

MATCH / 校验一致
文件与公布值一致。它不是病毒检测或安全认证，也不保证软件绝对安全；下一步是否安装由你决定。
MISMATCH / 校验不一致
先不要运行。确认下载版本与本页一致，再从官网的原始发布链接重新下载并重新检查。
FILE NOT FOUND / 未找到文件
重新从文件资源管理器复制实际文件的完整路径，包含磁盘、文件夹和完整文件名。不要把别人的路径直接当作自己的路径。
NO PATH / 没有输入路径
重新复制实际文件路径，再运行命令并在提示后粘贴。
READ ERROR / 读取失败
本次没有取得有效哈希，不能判断一致或不一致。确认窗口是 PowerShell、文件可读，并保留原始错误；不要把空输出当作校验结果。
其他错误或没有输出
保留完整错误文本，先确认是在 PowerShell 中粘贴了整段命令。没有实际结果时，不能认为校验完成。
