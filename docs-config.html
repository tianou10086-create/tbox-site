卡密激活成功，为什么模型还不能用？

产品授权与模型连接是两条链。卡密决定 T-Box 使用权限；模型 Key、网络、配额和视觉能力取决于你选择的服务商。

核对所选服务的配置、网络及额度，保留原始错误提示。T-Box 卡密不包含第三方模型调用额度。

不要把完整 API Key 粘贴到公开群聊或反馈模板中。

查看首次设置说明 →

哪些数据留在本地，哪些会发到云端？

本地 SenseVoice 转写在本机处理录音。主动调用云端模型、云端转写或视觉服务时，相关材料会按当前配置发送到所选服务商。

导入和整理默认在本地；调用云端分析前，先删除或打码不需要的身份证号、住址、电话等内容。不同服务的保存规则需要查看相应提供方说明。
